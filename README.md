# Climate Analysis Toolkit

This is a set of python scripts designed to analyse datafiles.

If your're interested in collaborating, email me at zephyr.goriely@dtc.ox.ac.uk

To install a copy of the toolkit, open a terminal and run:

    git clone git@github.com:zgoriely/climate-analysis.git


** This code is currently in development and not all features may work just yet **
